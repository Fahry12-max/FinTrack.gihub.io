# FinKasTra

## Tentang Project

FinKasTra (Finansial Kas Tracker) adalah personal finance tracker
yang dibuat untuk membantu pengguna mencatat, memantau, dan
membangun kebiasaan dalam mengelola keuangan.

## Awal Project

Tanggal mulai: 29 September 2026
Versi awal: V1

## Tujuan

- Mencatat pemasukan
- Mencatat pengeluaran
- Mencatat investasi
- Memantau total aset
- Membantu membangun konsistensi investasi
- Mengetahui pola penggunaan uang

## Konsep Utama

FinKasTra tidak hanya berfokus pada jumlah uang yang dimiliki,
tetapi juga pada kebiasaan pengguna dalam mengelola uang.

## Teknologi V1

- HTML
- CSS
- JavaScript
- Local Storage
- Git
- GitHub
- Vercel

## Rencana Pengembangan

Project akan dikembangkan secara bertahap berdasarkan hasil
penggunaan dan testing nyata.

Versi berikutnya tidak ditentukan hanya berdasarkan asumsi,
tetapi berdasarkan masalah dan kebutuhan yang ditemukan selama
penggunaan FinKasTra.
